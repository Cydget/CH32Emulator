# AI prompt log

This folder is the written log of the prompt sessions that created and changed this emulator.

For each session, keep two files:

- `session-YYYY-MM-DD.md` — the conversation itself: the user prompts, in order, and a running note of what the assistant did in response.
- `session-YYYY-MM-DD-summary.md` — a short summary of that session: goal, decisions, what was built, and what is still open.

Update both files during the session, not only at the end. Start a new pair of files when a new prompt session begins.
